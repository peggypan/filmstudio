## 技术栈

### 前端 (apps/web)
| 技术 | 版本 | 用途 |
|------|------|------|
| React | 18.x | UI框架 |
| TypeScript | 5.x | 类型安全 |
| Vite | 5.x | 构建工具 |
| Ant Design | 5.x | UI组件库 |
| Zustand | 4.x | 状态管理 |
| React Query | 5.x | 数据获取 |
| React Router | 6.x | 路由管理 |
| ECharts | 5.x | 数据可视化 |
| Fabric.js | 5.x | 画布编辑(分镜) |

### 后端 (apps/api)
| 技术 | 版本 | 用途 |
|------|------|------|
| NestJS | 10.x | Node.js框架 |
| TypeScript | 5.x | 类型安全 |
| Prisma | 5.x | ORM |
| PostgreSQL | 16.x | 主数据库 |
| Redis | 7.x | 缓存/会话 |
| MinIO | 最新 | 对象存储 |
| Passport | 0.7.x | 认证 |
| Bull | 4.x | 任务队列 |
| Socket.io | 4.x | 实时通信 |

### AI 集成
| 服务 | 用途 |
|------|------|
| OpenAI GPT-4 | 剧本生成、分析 |
| 文心一言 | 中文剧本优化 |
| Claude | 长篇剧本处理 |
| Midjourney API | 分镜图生成 |
| Stable Diffusion | 本地图像生成 |
| ElevenLabs | 语音合成/克隆 |
| Azure TTS | 备用语音合成 |
